Selector nocturno

Un selector de modo día / noche con animación, hecho como componente web. No depende de nada: funciona en HTML puro, React, Vue, Angular, Svelte o lo que uses.

Modo día

Tocalo: esta página cambia de tema con él y lo recuerda la próxima vez.

Código en GitHub Cómo instalarlo

Variantes

Chico: font-size: 9px
Arranca de noche: noche
Deshabilitado: disabled
Colores propios: variables --sn-*

Usarlo

<script type="module"
  src="https://cdn.jsdelivr.net/gh/carlos-illobre/selector-nocturno@main/selector-nocturno.js"></script>

<selector-nocturno></selector-nocturno>

<script type="module">
  document.querySelector('selector-nocturno').addEventListener('change', (e) => {
    document.documentElement.classList.toggle('oscuro', e.detail.noche);
  });
</script>

Todas las opciones, la instalación con npm y ejemplos para cada framework están en el README.
